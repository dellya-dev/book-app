# 📚 Book App

A simple React application that fetches book data from an external API and displays them in a clean and responsive interface. This project focuses on asynchronous data fetching, state management, and rendering dynamic content with React.

---

## ✨ Features

* Fetch book data from an external API
* Display a list of books dynamically
* Loading indicator while fetching data
* Error handling for failed requests
* Responsive layout
* Clean and simple user interface

---

## 📖 What I Learned

* Fetching data using the Fetch API
* Working with asynchronous JavaScript (`async` / `await`)
* Managing state with `useState`
* Fetching data with `useEffect`
* Conditional rendering (loading & error states)
* Rendering lists using `.map()`
* Organizing React components
